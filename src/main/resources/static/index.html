What JalRakshak does today

Only features that exist in the current prototype.

Four water parameters

pH, turbidity, TDS and temperature are shown side by side for the latest reading.

Saved history

Every reading is stored in MySQL, so charts and the table show how values changed over time.

Data freshness

Old readings are never called live. The dashboard tells you when data may be stale.

Honest assessment

The dashboard displays a saved model prediction when one is available; it is not a safety certification.

Clearly labelled demo mode

Present without hardware using simulated data that is never saved or mixed with real readings.

How it works

From sensor to dashboard.

  1. Sense

    An ESP32 reads pH, turbidity, TDS and temperature sensors. Continuous connection planned

  2. Send

    The reading is posted to the Spring Boot REST API.

  3. Store

    The API saves it with a timestamp in MySQL.

  4. View

    This dashboard loads the saved readings and refreshes every 5 seconds.

  5. Assess

    The backend stores a dataset-based ML prediction with a reading when all inputs are valid. Prototype

About the project

JalRakshak is a college project that uses an ESP32 with pH, turbidity, TDS and DS18B20 temperature sensors to collect water-quality readings. The readings are sent to a Spring Boot REST API and stored in MySQL. The dashboard displays saved readings, historical trends and dataset-based ML predictions.

Project status: Spring Boot API, MySQL persistence and dataset-based ML prediction integration are working in the prototype. Continuous ESP32 connectivity, sensor calibration and real-world model validation are still pending.

Important: ML predictions are experimental and should not be treated as certification that water is safe to drink.
